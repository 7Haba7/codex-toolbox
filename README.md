# codex-toolbox
Personal Codex AI toolkit: skills, memory, automation and development tools.

## Как пользоваться

Открой проект в Codex и опиши задачу обычными словами. Общие инструкции лежат в AGENTS.md. Профили в .codex/agents предназначены для среды Codex с поддержкой помощников. Например, попроси разработчика исправить ошибку, а ревьюера проверить исправление.

Запусти `python3 tools/context.py` из рабочей копии Git. По умолчанию скрипт выводит до 8 000 000 000 символов. Для короткой сводки укажи свой предел, например `python3 tools/context.py --limit 3000`. Сводка показывает ветку, состояние файлов и статистику изменений без их содержимого.

Для сводки по одной папке или файлу используй `python3 tools/context.py --path tools --limit 1000`. Путь отсчитывается от рабочего каталога. Чтобы продолжить предыдущую задачу, попроси Codex прочитать HANDOFF.md.

Автопроверки запускаются при push и pull request. Локальный запуск на Python 3.11 или новее: `python3 -m unittest discover -s tests -v`.
