Отвечай пользователю по-русски, если он не просит другой язык. Определи ожидаемый результат и способ его проверить. Простую задачу выполняй напрямую. Для большой задачи сначала найди точки входа через git ls-files и rg. При необходимости запусти python3 tools/context.py из рабочей копии. Читай только относящиеся к задаче файлы и участки журналов.

Если задача выигрывает от делегирования и среда поддерживает помощников, выбери роль из .codex/agents. Дай помощнику узкий вопрос, пути и критерий готовности. Разделяй области записи. Для последующей работы передай цель, проверенные факты, изменённые пути, выполненные проверки и один следующий шаг. Храни персональные данные и ключи вне репозитория.
