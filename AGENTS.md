Отвечай пользователю по-русски, если он не просит другой язык. Определи ожидаемый результат и способ его проверить. Простую задачу выполняй напрямую. Для большой задачи сначала найди точки входа через git ls-files и rg. Когда нужна короткая сводка по рабочей копии, запусти `python3 tools/context.py --limit 3000`. Если нужный путь уже известен, добавь `--path` с этим путём. Читай только относящиеся к задаче файлы и участки журналов.

Если задача выигрывает от делегирования и среда поддерживает помощников, выбери роль из .codex/agents. Дай помощнику узкий вопрос, пути и критерий готовности. Разделяй области записи. Для последующей работы передай цель, проверенные факты, изменённые пути, выполненные проверки и один следующий шаг. Храни персональные данные и ключи вне репозитория.

Если пользователь просит продолжить прошлую задачу, прочитай HANDOFF.md и сверь запись с текущей веткой. При завершении этапа длительной работы обнови там результат, проверки и следующий шаг. Записывай только сведения, пригодные для публичного репозитория.

Если пользователь передал готовый план из ChatGPT, используй его как отправную точку. По запросу «Выполни план из HANDOFF.md» прочитай раздел «Текущая задача». Сверь указанные файлы и условия с рабочей копией, выполни план и проверь результат. Пересматривай шаги, только если состояние проекта этого требует.
