# Состояние codex-toolbox

Фильтр по буквальному пути добавлен в tools/context.py. Проверки семи профилей и сводки Git прошли локально на Python 3.12. Команда для повторения: `python3 -m unittest discover -s tests -v`. Конфигурация GitHub Actions находится в .github/workflows/check.yml.

Следующий шаг — проверить запуск профиля explorer в сеансе Codex с открытым проектом. В проверенной среде вложенный Codex CLI остановился при создании песочницы bwrap до старта помощника. Проверочное задание: попросить explorer прочитать tools/context.py и назвать значение --limit по умолчанию. Ожидается 4000 и подтверждение вызова роли explorer.
