# Состояние codex-toolbox

Фильтр по буквальному пути добавлен в tools/context.py. Проверки семи профилей и сводки Git прошли локально на Python 3.12. Команда для повторения: `python3 -m unittest discover -s tests -v`. Конфигурация GitHub Actions находится в .github/workflows/check.yml.

В сеансе Codex отдельному помощнику явно передали профиль `.codex/agents/explorer.toml`. Помощник прочитал код и нашёл в `tools/context.py` значение `--limit` по умолчанию — 4000 символов. Оба теста из `tests/test_toolbox.py` прошли на ревизии `3df61ba`.

Следующий шаг — проверить автоматический выбор проектного профиля при вызове роли `explorer` по имени. Вложенный Codex CLI завершился до вызова роли с ошибкой файловой системы, доступной только для чтения. Для проверки нужен сеанс Codex с загруженной конфигурацией проекта и доступом на запись в служебный каталог CLI.
